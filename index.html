Política de Privacidade

Este aplicativo, Luz da Palavra, foi desenvolvido por Gabriel Archanjo Lima como uma ferramenta de reflexão pessoal baseada em princípios bíblicos.

Coleta de informações

O aplicativo pode coletar informações fornecidas voluntariamente pelo usuário, como textos inseridos para geração de reflexões.

Uso das informações

As informações são utilizadas exclusivamente para gerar respostas e melhorar a experiência do usuário.

Compartilhamento de dados

O aplicativo pode utilizar serviços de terceiros para processamento das informações, sem compartilhamento indevido de dados pessoais.

Armazenamento

Não armazenamos dados pessoais sensíveis permanentemente.

Segurança

Medidas razoáveis são adotadas para proteger as informações.
